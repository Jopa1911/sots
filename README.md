# AI agent za vežbanje zahtevnih razgovora

**Projekat 6 — AI konverzacioni agent za simulaciju razgovora u obrazovnom okruženju**

Prototip govornog AI agenta koji glumi **ljutitog roditelja** u telefonskom razgovoru sa **nastavnikom**. Ljutnja agenta raste ili opada u zavisnosti od strategija koje korisnik koristi, a pre i posle razgovora korisnik prolazi kroz kartice za učenje napravljene na osnovu dataseta ESConv.

**Trenutna faza:** 🟡 Faza 1 — istraživanje i planiranje · **Dnevnik rada:** [DNEVNIK.md](DNEVNIK.md) · **Rad:** [PDF](docs/rad/projekat6_rad.pdf)

## Struktura repozitorijuma

```
├── README.md
```
